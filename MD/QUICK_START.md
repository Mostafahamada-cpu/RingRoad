# ⚡ بدء سريع - Ring Roads

## 🚀 تشغيل التطبيق في 3 دقائق

### الخطوة 1: التثبيت الأساسي

```bash
# تثبيت Node.js (من https://nodejs.org)

# إنشاء مشروع جديد
npx react-native init RingRoads --template react-native-template-typescript

cd RingRoads
```

### الخطوة 2: نسخ الملفات

1. افتح ملف `App.js` (أو `App.tsx`)
2. احذف كل المحتوى
3. انسخ محتوى `RingRoads_RealEstate_App.jsx` بالكامل
4. احفظ الملف

### الخطوة 3: التشغيل

#### على Android:
```bash
npx react-native run-android
```

#### على iOS:
```bash
# أولاً تثبيت المتطلبات
cd ios
pod install
cd ..

# ثم التشغيل
npx react-native run-ios
```

## 🎮 التحكم بالتطبيق

### التنقل بين التبويبات
- اضغط على **📊 لوحة المعلومات** لرؤية العقارات
- اضغط على **💰 العمولات** لحساب العمولات

### في لوحة المعلومات
- اضغط على أي عقار لرؤية التفاصيل الكاملة
- اضغط مرة أخرى لإخفاء التفاصيل

### في حساب العمولات
- عدّل **مبلغ المشتري** والبائع
- عدّل النسب المئوية للعمولات
- شاهد الحسابات تتحدث فوراً
