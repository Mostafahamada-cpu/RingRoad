# 🏢 Ring Roads - تطبيق إدارة العقارات

<div dir="rtl">

## 📱 نظرة عامة

تطبيق **React Native** احترافي وشامل لشركة **Ring Roads** العقارية يوفر:

- 📊 **لوحة معلومات متقدمة** لعرض جميع العقارات مع تفاصيلها الكاملة
- 💰 **حاسبة عمولات ذكية** لحساب فوري وديناميكي للعمولات
- 🎨 **تصميم احترافي** بألوان جذابة وواجهة سهلة الاستخدام
- 🌍 **دعم كامل للغة العربية** مع RTL
- 📱 **متجاوب تماماً** مع جميع أحجام الشاشات

## 🚀 البدء السريع

### المتطلبات
- Node.js >= 14
- npm أو yarn
- Android Studio / Xcode (اختياري)

### خطوات التثبيت

```bash
# 1. إنشاء مشروع جديد
npx react-native init RingRoads

# 2. الانتقال للمشروع
cd RingRoads

# 3. استبدال App.js بـ RingRoads_RealEstate_App.jsx

# 4. تشغيل على Android
npx react-native run-android

# 5. أو تشغيل على iOS
npx react-native run-ios
```

**📖 تفاصيل أكثر في ملف `QUICK_START.md`**

## 🧮 الحسابات الرياضية

### معادلة العمولات
```
Total_Money = Buyer_Money + Seller_Money

Agent_Buyer = (Agent_Buyer_Percent / 100) × Total_Money
Agent_Seller = (Agent_Seller_Percent / 100) × Total_Money
Inspection = (Inspection_Percent / 100) × Total_Money
Manager = (Manager_Percent / 100) × Total_Money

Total_Commission = Agent_Buyer + Agent_Seller + Inspection + Manager
```

### مثال عملي
```
Buyer_Money = 30,000
Seller_Money = 50,000
Total = 80,000

Agent_Buyer (11%) = 8,800
Agent_Seller (11%) = 8,800
Inspection (5%) = 4,000
Manager (2%) = 1,600
───────────────────
Total Commission = 23,200 ✅
```
