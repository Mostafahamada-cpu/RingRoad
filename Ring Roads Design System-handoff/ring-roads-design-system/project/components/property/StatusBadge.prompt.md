Small colored pill for a property's state. Pair the status with matching bilingual copy.

```jsx
<StatusBadge status="available">متاح · Available</StatusBadge>
<StatusBadge status="sold">مباع · Sold</StatusBadge>
<StatusBadge status="rented">مؤجر · Rented</StatusBadge>
```

Colors are fixed to the semantic tokens: green / red / amber.
